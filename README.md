# Resume-AI 🧠

AI-powered Resume Analyzer & Optimizer

## Structure
```
Resume-AI/
├── frontend/   → React + Vite app
└── backend/    → Node.js + Express API
```

## Quick Start

### Backend
```bash
cd backend
npm install
cp .env.example .env    # fill in your keys
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173
